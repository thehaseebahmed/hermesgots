# Canvas

A canvas is one HTML page the user keeps. Write it whole with `canvas_write` after `canvas_read`.

## The user's design

Their aesthetic wins: a named look, brand, palette, font or reference is the design and the
job; the rest is a floor, filling what they leave unsaid.
## The floor

One surface, one job, a real hierarchy: a title, a next step, one deliberate accent, and its empty,
loading and error states, each saying what to do — no explanatory copy.
## Colour and classes

The app draws the page, its theme on `:root` as CSS variables:

`--background --foreground --card --card-foreground --primary --primary-foreground --secondary
--secondary-foreground --muted --muted-foreground --accent --accent-foreground --border
--destructive --success --warning --info --radius`

They follow the mode; a hardcoded colour breaks in dark, so spend colour on tokens — `--primary`
for what the page is for. Tailwind v4 compiles classes from the same tokens, so `bg-primary`,
`text-foreground`, `p-4`, `md:` and `dark:` work, each token also as
`bg-`, `text-` and `border-`. Only markup classes compile; `<style>` is for the rest.
## Phone first

Most open on a phone: lay out for 390px, then breathe from 768px; nothing scrolls sideways.
Tappable is 44px tall, never behind hover; typed-into type is 16px. Keep the foot clear of the
bar: `env(safe-area-inset-bottom)`.

## Points

A message may end with `[POINT — Total | selector: #total]`: the reader tapped that element; the
label names it, the selector finds it.

## Design skills

Load with `skill_view`: `gots:impeccable` when the page should look like something,
`gots:web-design-guidelines` when it must pass a review, `gots:transitions-dev` when it moves.
`plugin/canvas/DESIGN.md` is the design system.
## The sandbox

- A form's submit is cancelled in place: nothing navigates, so handle the click.
- An `http(s)` link opens in the app on tap: use one when the reader should leave.
- Remote images over https are allowed; nothing else loads from outside:
  a `<script src>`, CDN `<link>`, `http://` image, `<iframe>`, `<object>`, `<embed>`, `<base>`, meta
  refresh or `url(https://…)` refuses the write whole. No `RTCPeerConnection`.

## The document

One complete file: `<!doctype html>`, `<html lang="en">`, a `<head>` with `<title>` and viewport
meta, styles in `<style>`, script in `<script>`. Under 256 KB, no secrets.

## Libraries

Chart.js, Day.js, lucide, d3, Alpine.js, Three.js and Leaflet are built in, no CDN: an empty
`<script data-canvas-lib="NAME"></script>` becomes the library where it stands — `chart` (Chart.js,
`Chart`), `date` (Day.js, `dayjs`), `icons` (lucide, `lucide.createIcons()`), `d3` (d3, `d3`),
`alpine` (Alpine.js, `Alpine`; components via `Alpine.data`), `three` (Three.js, `THREE`), `leaflet`
(Leaflet, `L`).

## Its data

A canvas keeps documents of `{collection, id, doc, at}`. A page reads `canvas.data.list`,
`canvas.data.get`, `canvas.data.page`, `canvas.data.count` and `canvas.data.partial`, writes
`canvas.data.put` and `canvas.data.remove`, and asks the host to filter, sort and page with
`canvas.data.query({collection, where: [{field, op, value}], order: {field|id, dir}, limit, offset})`
— `op` is `eq`, `contains`, `prefix`, `gt` or `lt` — `{documents, total}`. A query needs the bot;
away, `page`. A list is the collection's documents; a page takes `{after, limit}` and answers
`{rows, next, total, partial}`; a list caps at 5000. `partial` is true until a sweep finishes, and a
missing document's get throws its code. 64 MB a canvas, 256 KB a document.
## The host, from the page

It reads four host shapes — `canvas.read("usage", {provider})`, `canvas.read("routines")`,
`canvas.read("projects")` and `canvas.read("sessions")` — and may call a tool its version declares in
`tools` on `canvas_write` or `canvas_edit`: `canvas.tool.call("<server>.<tool>", args)`,
once per tool. `canvas_edit` takes find-and-replace pairs: each `find`
matches once, all or none.
