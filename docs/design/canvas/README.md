# Canvas design references

Mobile screens of products where you build something with an agent, then edit it and use it. Captured with Playwright in Chromium at a 390px-wide viewport (iPhone 13 profile, device scale 2) on 2026-11-07, signed out.

None of these is a live editor. Lovable's project editor, Claude's artifact panel and ChatGPT Canvas all need an account, and lovable.dev and claude.ai answer a signed-out browser with a bot check. Each Playwright capture is the closest public page. The `*-store-*` files are not captures: they are the phone screenshots from each app's Google Play or App Store listing, downloaded from the store's image CDN on 2026-11-07 and scaled to at most 900px wide. They are the vendor's promotional images, framed and captioned, so they show the real phone UI as the vendor chose to present it. The table says what each file is.
