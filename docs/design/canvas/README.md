# Canvas design references

Mobile screens of products where you build something with an agent, then edit it and use it. Captured with Playwright in Chromium at a 390px-wide viewport (iPhone 13 profile, device scale 2) on 2026-11-07, signed out.

None of these is a live editor. Lovable's project editor, Claude's artifact panel and ChatGPT Canvas all need an account, and lovable.dev and claude.ai answer a signed-out browser with a bot check. Each capture is the closest public page, and the table says what it is.
