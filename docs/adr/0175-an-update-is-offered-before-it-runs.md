# An update is offered before it runs

The firmware screen used to start its walk the moment it opened, so a reader who opened it to see which build the charm ran flashed the charm instead. An update is now a state the reader enters: the screen draws what the charm needs and one `Install` button, and nothing leaves the phone until that tap. The trade is an extra tap and an offer the walk has to hold, against a reboot nobody asked for on a device that people pick up to look at.
